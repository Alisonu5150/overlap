    How do I get a calendar file?
    • Google Calendar: Settings → Import & export → Export. It downloads a zip; unzip it, one .ics per calendar.
    • Apple Calendar: File → Export → Export…
    • Outlook: File → Save Calendar (or Share → Publish, then use "Add link").

    "Add link" works with subscription URLs (webcal:// or https://) from hosts that allow browser access. If a link is blocked, download the file instead.
